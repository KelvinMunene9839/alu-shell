# alu-shell

This repository contains shell exercise scripts.

## init_files_variables_and_expansions
- **0-alias**: defines an alias `ls` as `rm *`.
- **1-hello_you**: prints `hello` followed by the current user.
- **2-path**: appends `/action` to `PATH`.
- **3-paths**: prints the number of directories in `PATH`.
- **4-global_variables**: lists environment variables.
- **5-local_variables**: lists some shell variables plus function declarations.
- **6-create_local_variable**: creates local variable `BEST=School`.
- **7-create_global_variable**: creates global variable `BEST=School`.
- **8-true_knowledge**: prints `128 + TRUEKNOWLEDGE`.
- **9-divide_and_rule**: prints `POWER / DIVIDE`.
- **10-love_exponent_breath**: prints `BREATH ** LOVE`.
- **11-binary_to_decimal**: converts binary from `BINARY` to decimal.
- **12-combinations**: prints all combinations of two letters except `oo`.
- **13-print_float**: prints `NUM` with two decimals.
- **14-decimal_to_hexadecimal**: converts `DECIMAL` to hex.
- **15-rot13**: applies ROT13 to stdin.
- **16-odd**: prints every other line from stdin (intended to start from 1st).
- **17-water_and_stir**: placeholder for base conversion exercise.
